# ANPR vehicle recognition
The evaluation prototype helps a gate operator review a vehicle observation, read a plate from an uploaded image, and find the original image when reviewing an alert.

## Demonstrated workflow
An operator can label the observation source, submit an image, review detected text, register a provisional vehicle and flag a plate for review. A repeat observation of a listed plate generated an alert during a local demonstration. Event history can be exported as CSV.

## Evaluation scope
Image upload was exercised with a reference photograph. Single-frame video and local test-stream capture were also demonstrated. Representative Indian-plate accuracy, physical-camera interoperability and production deployment remain under evaluation.
